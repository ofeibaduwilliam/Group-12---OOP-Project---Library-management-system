# Library Management System

## Overview

This project is a **Library Management System** developed as part of a school assignment. The application is written in **C++** and uses **CSV files** as a simple database for storing and retrieving library records.

The system demonstrates fundamental concepts of file handling, object-oriented programming, and data management in C++.

---

## Features

* Add new books
* View available books
* Update book records
* Delete book records
* Store data using CSV files
* Simple console-based user interface

---

## Technologies Used

* **Language:** C++
* **Database:** CSV (Comma-Separated Values)
* **IDE:** Any C++ compatible IDE (Code::Blocks, Visual Studio, VS Code, Dev-C++, etc.)
